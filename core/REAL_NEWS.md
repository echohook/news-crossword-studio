# 真實新聞快照驗收 — 2026-10-01

此案例使用人工瀏覽核對、人工編寫題目的固定新聞資料。它驗證真實新聞可以進入既有管線，並非自動爬蟲或完整的新聞編輯系統。

## 重跑方式

在原型資料夾執行：

```powershell
node cli.mjs pipeline examples/news-real-20261001.json --attempts 256 --seed 2
node cli.mjs validate examples/news-real-puzzle.json
node cli.mjs validate examples/news-real-invalid-zhi-che.json
node cli.mjs batch examples/news-real-batch.json
npm test
```

成功配置是 **8×8、12 題、2／3／4 字分布 3／5／4**，V01～V08 全部 PASS，兩則標記重點新聞均入盤。完整文字輸出見 reports/news-real-20261001.txt。

最後一個失敗盤的 validate 必須回傳 INVALID；在合法盤外另加一個未宣告的直向「智撤」，獨立掃描會使 V04 FAIL。批次驗收把這個預期失敗視為測試通過，不會把盤面改判 VALID。

## 保留的限制

Event Score 80 是本案例的初步編輯評分；Answer Score 75～94 是詞語熟悉度及題目可用性的初步判斷，均不是客觀排名或已校準模型。示範期間的事件分類沒有涵蓋所有可能議題。

v1.5.0 的 seed 2、256 次搜尋得到上述配置。v1.2.0 新增重點新聞選題偏好；預設 seed 1、48 次搜尋也能涵蓋兩則重點，字數為 3／5／4。其餘設定可能有不同盤面，報告會列出缺漏；有界啟發式搜尋不保證最優解或重點新聞全數入盤。細節見 SELECTION.md。

新聞快照核對於 2026-10-01；未宣稱所有議題都已排除後續更正。內容唯一性、長輩難度及正式出版前的新鮮度仍須編輯複核。整體管線維持 REVIEW_REQUIRED，approved_for_print=false。幾何 VALID 與正式內容核准分開呈現。

## 回歸測試

新增七項固定快照測試，涵蓋資料來源欄位、完整盤面、重現性、公布日期與舊事件差異、過度確定的投資題目、缺少摘錄支持、額外直詞。測試完全離線，不依賴網站在未來仍顯示相同內容。
