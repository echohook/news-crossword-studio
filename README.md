# 時事填字樂 — 網路操作版 v1.8.0

以瀏覽器操作，供多人使用。每位出題者的工作在自己的瀏覽器中進行，彼此不共用可變狀態。
目前提供產題、更新題庫、本次成果三個工作區。一次產出 1～7 份，每份預設 8 題時事＋4 題成語，整批題目與答案不得重複。每份沿用 Solver、獨立 Validator、娛樂新聞排除及來源支持檢查。

## 使用
1. 選擇份數，按「產生題目」。
2. 檢查作答與答案預覽；只有指定份數全部完成、V01～V08 及不重複檢查通過，才可下載 A4 PDF。
3. 從「更新題庫」修改提示、增添有來源的成語或新聞，套用後下載題庫檔。
4. 匯入題庫檔可供自己下次使用或交給其他出題者。接受混合題庫、獨立新聞 JSON、成語題庫 JSON。
5. 題目檔保存盤面、提示、答案與來源，從「本次成果」重新匯入時會重新驗證。

題庫編輯與本次成果是目前頁面的工作狀態，沒有雲端共用題庫或帳號資料庫。離開前請下載保存，重新開啟後匯入；不會將他人的工作覆蓋到網站預設題庫。
網站預設資料是 2026-09-25～2026-10-01 固定新聞快照，不是即時新聞。目前僅四個成語，因此內附資料能完成一份混合題；指定更多份會回報不足。至少須有 28 個不同成語及 56 個不同時事答案才有機會完成七份，仍須題目自然、來源支持並能交叉。未實作自動新聞蒐集，改日期不會更新新聞。

## 驗證
- 已有核心 168 項測試通過。
- 新增六項網路版匯出及題庫檢查通過。
- 實際瀏覽器驗證 11 個操作情境：份數、產題、答案切換、中文 PDF、缺份攔截、7 份限制、兩位使用者互不覆蓋、改題與匯入、錯誤匯入保留原資料、成果重載、手機版無橫向溢出。
- PDF 兩頁已渲染並目視確認所有中文字完整，A4、答案不洩漏及日期格式均通過。
- 瀏覽器原生 WebMCP 不可用，故無法驗證真實原生工具註冊；已加入功能偵測，缺少支援不影響一般使用，沒有宣稱該能力通過。
- Noto Sans TC 使用 SIL OFL 授權，授權檔在 dist/FONT-LICENSE.txt。PDF 完整嵌入 Regular／Bold 字型，避免 CJK 子集缺字，下載檔約 9 MB。

## 開發與部署
```
npm install
npm run build
npm test
```
build.mjs 打包瀏覽器產題及 PDF 工作執行緒；核心保持在 core/。標準 Node crypto 在瀏覽器以 js-sha256 相容介面替代。
Sites 靜態資產位於 dist，網站識別保存在 .openai/hosting.json。重新部署須沿用原 project_id。網站不需要 API 金鑰、伺服器端 Python 或 Windows 字型，所有必需資產均由同一網站提供。
源碼與可用網址的交付文件保存於 outputs。維護時不得重新建立另一個 Site 冒充此網站。
