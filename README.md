# 時事填字樂 — 自動題庫網路版 v1.10.0

[開啟網站](https://echohook.github.io/news-crossword-studio/) · [另一入口](https://news-crossword-studio.echoman.chatgpt.site)

開啟網站即載入雲端共用的最新題庫。選擇 1～7 份，按「產生題目」，完成後下載 A4 作答與答案 PDF。不必手動新增、保存或匯入新聞。

## 自動搜尋與加入

雲端約每六小時讀取中央通訊社官方 RSS 的政治、國際、兩岸、財經、科技、生活、社會、地方、體育分類；不讀取娛樂分類，並再次排除娛樂標題及娛樂網址。使用最近七天的報導標題、日期、來源連結；高爾夫相關報導另使用發布者提供的 RSS 摘要，不擷取文章全文或圖片。

程式從報導標題及高爾夫新聞 RSS 摘要中擷取熟悉的 2～4 字國家、地名、人物、機關及用語，產生完整的事件問句或詞義提示，不使用圓圈遮字、片段截取或補字玩法。答案必須出現在原始來源，提示不洩漏本題或其他候選答案；重疊短詞、不合格或無法清楚描述的候選會排除。這是可重複的用字擷取，沒有宣稱使用 AI 完成完整語意或事實查核。每題保留原始來源，可在「自動題庫」查看。

更新會合併仍在七天期限內的前次新聞，按來源網址去重，最多保留 180 則事件及 500 個不同候選答案。新題庫通過條件後才取代舊題庫，保存於 data/auto-news.json。部分 RSS 失效時使用其他來源；全部失敗或没有合格新題時不覆寫前次資料，下次排程自動重試。網站連線失敗時使用內附最近一次題庫，顯示更新時間與狀態，仍會排除已過期的新聞。

排程約每六小時，設定時間為臺灣 02:17、08:17、14:17、20:17；GitHub 排程可能延後。兩個網站開啟時均載入同一份雲端題庫。「取得最新題庫」取得最近已完成的更新，不會讓每位訪客另行執行蒐集。初次已實際讀取來源並完成題库更新，無須 API 金鑰、付費模型或額外設定。

## 產題規則

每份預設 12 題，優先時事 8 題與成語 4 題；成語不足或無法排入時以時事補足，允許零成語。8×8 優先，9×9 次之，10×10 上限。2、3、4 字平均為最佳化目標；新聞用字不足時不為湊比例加入無來源答案。

同批題目與答案不能重複。候選數量足夠仍不保證能排出全部合法盤面；若指定份數未全數完成，顯示實際份數並禁止下載不完整 PDF，可減少份數或等待更新。首輪自動題庫實测能完成多份，並已下載兩份四頁 PDF。

Solver 與 Validator 保持分離；每份 V01～V08 反向掃描通過，無多餘橫直字串、字衝突或中斷，每題至少一個有效交叉。PDF 橫向用阿拉伯數字、直向用國字；作答頁在前，答案頁在後，只有作答頁顯示填答日期。

產出的題目成果仍在自己的瀏覽器處理，離開前請下載 PDF 或題目檔。自訂題庫的進階工具可用，但其修改只屬本次開啟期間；需要留存時自行匯出，不會覆寫共用自動題庫。四字成語沿用有辭典來源的候選，成語不會阻礙自動時事更新。

## 開發與部署

需要 Node.js 24：

    npm ci
    npm run update-news
    npm --prefix core test
    npm test
    npm run build

news/ 為新聞來源、用字詞表、蒐集與提示產生介面；scripts/update-news.mjs 負責資料更新；src/auto-bank.mjs 負責自動載入、過期排除及離線保留。core/ 仍保留獨立 Solver、Validator、選题及 A4 介面。舊 core/examples/ 為歷史測試資料，不再作為網站的預設新聞題庫。

.github/workflows/pages.yml 在 main 更新、手動啟動及六小時排程時跑完整測試，自動搜尋並保存自然提示的題庫，再建置、發布 GitHub Pages。只使用平台內建權限；程式無登入憑證或個人 API 金鑰。由平台憑證寫入的題庫提交不另觸發新的更新迴圈。來源完全失效時當次流程失敗，原網站與前次資料持續可用，下次排程重試。

原 Sites 靜態網站維護時沿用 .openai/hosting.json 的 project_id；網站程式更新須走原發布流程，日常題庫更新由共同題庫自動載入，不必重新部署 Sites。

## 驗證与來源

168 項核心測試與 41 項網站／自動題庫測試全數通過，包括「智撤」額外字串、零成語、日期、娛樂排除、來源故障、不覆寫舊資料及提示來源支持。實際瀏覽器驗證自動載入、取得更新、兩份不重複題目、中文 PDF、手機畫面與連線失敗保留原題庫。

新聞來源與使用範圍見 [中央通訊社官方 RSS 說明](https://www.cna.com.tw/about/rss.aspx)，逐題標示發布者與原始網址。Noto Sans TC 使用 SIL OFL 授權，dist/FONT-LICENSE.txt 保留授權全文，PDF 完整嵌入 Regular/Bold 字型。專案尚未指定整體原始碼授權。瀏覽器 WebMCP 使用功能偵測，未宣稱原生支援已驗證。

高爾夫新聞已納入體育自動搜尋；支援三字「高爾夫」與四字「高爾夫球」，完整名稱優先，來源支持、字數提示與答案不洩漏皆有回歸驗證。

高爾夫擴充包含 38 個 2～4 字運動專門用語：果嶺、桿弟、球道、球桿、沙坑、推桿、柏忌、標準桿、一桿進洞等。只有真實高爾夫新聞標題或來源 RSS 摘要出現該詞時，才自動納入候選；不把沒有新聞支持的詞塞入當期題庫。小鳥、老鷹另須符合高球得分語境，避免動物同名詞；沙坑、開球與球道也不會因其他運動而誤納入。七天內高球報導優先保留最多 24 則，避免大量其他新聞將其擠出容量。來源完全沒有高球用語時不捏造新聞，後續排程會繼續自動搜尋。

果嶺、桿弟、球桿的用語說明參考 [R&A 果嶺](https://www.randa.org/zh-TW/rog/the-rules-of-golf/rule-13)、[R&A 桿弟](https://www.randa.org/zh-TW/rog/the-rules-of-golf/rule-10)、[R&A 裝備品](https://www.randa.org/zh-TW/rog/the-rules-of-golf/rule-4)，保留在候選的 term_reference；當期新聞原文支持仍由 source_support 獨立核對。news/golf.mjs 是高球用字、意思與語境介面。

## 自然題目 v1.10.0

所有新自動題目採完整事件描述或詞義問句，不使用圓圈遮字。例如「本週報導用語：以東京為首都、使用日圓的是哪個島國？（2字）」提示日本；「本週報導用語：替選手攜帶裝備、協助判讀路線的人，稱為什麼？（2字）」提示桿弟。事件題保留原標題的事實限定語，僅在主詞與敘述能構成完整問句時使用；無法清楚描述的未知用語暫時跳過。

news/clues.mjs 管理自行撰寫的完整詞義提示與事件問句介面。詞義提示屬一般知識描述，相關報導只用來證明當期有提及這個答案，沒有把詞義誤稱為報導原文；來源摘錄仍原樣保留。候選間若會互相洩漏完整答案，保留可用組合，不再遮掉文字。瀏覽器也會排除舊自動题庫中的圓圈提示，離線備份則由新版自然題庫提供。過往已下載的 PDF 不會被自動改寫，請重新產題。
