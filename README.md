# 時事填字樂 — 多元進階出題 v1.12.0

[開啟網站](https://echohook.github.io/news-crossword-studio/) · [另一入口](https://news-crossword-studio.echoman.chatgpt.site/)

對象是具社會經驗的成年與年長讀者。開啟即載入自動更新的新聞題庫，選擇 1～7 份，產題後下載 A4 作答與答案 PDF。題目使用事件敘述、政策影響、詞義應用及成語情境，不使用圓圈遮字、首字提示或首都國旗型百科題。

## 本版修正

每份預設 12 題，國名與地名合計最多 2 題，至少涵蓋 4 個答案題材；同一題材最多 4 題。專名合計最多 4 題，其中機關組織最多 2 題，避免把地名偏重改成機關名稱偏重。

至少 6 題使用已編輯的應用型詞義，至少 2 題使用本期新聞的完整事件線索。難度採中等至中上：結合社會、政策、制度、因果與生活經驗，避免以冷僻知識或模糊敘述增加困難。這是可檢查的編輯結構，尚未以讀者實測校準答對率。

例如「名目所得不變時，會侵蝕實質購買力的總體經濟現象」提示通膨；「交戰方暫停武力行動的安排，並不等同已達成永久和平協議」提示停火。國名僅在有完整近期事件線索時加入，停用以首都、國旗、地標直接提示國名的舊線索。

政治、國際、兩岸、財經、科技、生活、健康、社會、法律、環境、文化、體育及高爾夫相關新聞均可進入候選，持續排除娛樂新聞。候選仍須有七天內來源、完整自然答案與合格線索；不代表每份會含全部類別。

## 自動題庫

雲端每六小時讀取[中央通訊社官方 RSS](https://www.cna.com.tw/about/rss.aspx)的全部 10 個非娛樂分類：政治、國際、兩岸、產經證券、科技、生活、社會、地方、文化、運動。不訂閱娛樂分類，並檢查網址、標題及發布者提供的 RSS 前言。

使用新聞標題、日期、網址及 RSS 前言，不擷取全文或圖片。原始新聞摘錄與中央社發稿訊頭保留，逐題可查看來源。關鍵字必須在原始摘錄中完整出現；以較長自然詞優先，並對高球、海警、衛星等多義詞檢查語境。

一般詞義來自自編線索字庫，報導證明該詞與本期有關，不把自編詞義當成新聞原文。事件線索保留標題的行動、評估或計畫等限定語，改用完整的事物描述代替主詞，不刪個別文字，也不改寫成已發生。無法產生清楚線索的詞會跳過；這不是 AI 全文事實查核服務。

更新合併七天內前次新聞，依網址去重，最多保存 180 件事件、500 個不同答案。七天內高球報導優先保留最多 24 件；果嶺、桿弟、標準桿等用語仍須有高球新聞實際支持。小鳥、老鷹須符合高球得分語境，不把動物同名詞當成運動用語。

排程設定為臺灣 02:17、08:17、14:17、20:17，平台可能延後。成功更新保存在 data/auto-news.json，兩個入口開啟時載入同一份共用題庫。部分來源故障使用其餘來源；全部失效或沒有合格新題時保留前次資料，下次排程重試。連線失敗則使用網站內附最近一次題庫，顯示時間與狀態並排除過期新聞。

## 排盤與驗證

每份優先 10 題新聞及 2 題情境成語；成語不足或無法排入時由新聞補足，允許零成語。2、3、4 字平均為最佳化目標，單一字數以不超過一半為原則。優先 8×8，其次 9×9，上限 10×10。

同一批各份的完整答案與題目不能重複；共享單字與交叉字仍可使用。候選數量、事件線索數量、題材及交叉幾何都會影響可產份數。網站顯示估算上限，不保證指定份數必定達成；不足時顯示實際結果並禁止下載不完整批次 PDF，不重複答案或放寬難度來湊份數。

Solver 每次加入單字或交叉詞對前檢查題材與難度上限；完成後由獨立的 Q01～Q06 選題檢查重算。難度標記不能讓任意線索通過：應用詞義必須符合已登錄句子，事件線索必須吻合綁定事件。依答案本質分類，不能把國名標成科技新聞來避開地理限制。

原有獨立 Validator 仍反向掃描整盤，要求所有橫直連續兩字以上字串與正式答案一致，V01～V08 全部通過。每題至少一個真實交叉，禁止額外「智撤」等字串、字衝突、貼字或阻隔中斷。選題檢查獨立於字盤檢查，兩者都通過才能接受一份題目；匯出 PDF 時再次驗證。

PDF 橫向編號用阿拉伯數字、直向用國字。作答頁在前、答案頁在後；只在作答頁顯示填答日期。既有版面與大字體保持，較長線索若超出版面會阻擋匯出。

過去下載的題目或 PDF 不會自動改寫，請重新整理網站並重新產題。本次成果在個人瀏覽器處理，離開前下載留存。進階自訂題庫仍可用，修改不會覆寫共用自動題庫。

## 開發與部署

需要 Node.js 24：

    npm ci
    npm run update-news
    npm --prefix core test
    npm test
    npm run build

core/experienced-definitions.mjs 管理應用詞義與完整事件描述介面；core/editorial.mjs 負責難度與題材分類、上限及完成後的獨立檢查。core/solver.mjs 處理搜尋與增量放置，core/validator.mjs 僅反向驗證盤面。後續仍可接入其他新聞、題目生成及 PDF 介面。

experienced-adults-v1 為新自動題庫預設規格。舊合成測試與歷史成果保留原相容模式；自動題庫不因缺少舊標記而回到基礎出題。固定回歸資料明確標示為合成情境，不當作當期新聞。

.github/workflows/pages.yml 在 main 更新、手動啟動及六小時排程時執行完整測試、蒐集、保存及部署 GitHub Pages。平台憑證寫入的題庫提交不會再次觸發更新迴圈。原 Sites 維護沿用 .openai/hosting.json 的 project_id，程式更新另經原來源同步與發布；日常題庫透過共用資料自動載入。

回歸測試涵蓋國名地名過多、偽裝分類、機關或題材集中、舊式簡單線索、事件不確定性、新聞多義詞、RSS 前言、娛樂排除、來源故障、可重複排盤、整批不重複及 PDF 不信任已存 PASS 的情況。歷史 V01～V08、「智撤」及零成語案例持續保留。

## 來源與字型

逐題保留中央通訊社原始網址。RSS 使用範圍依[中央社規範](https://www.cna.com.tw/about/rss.aspx)。詞義由編輯撰寫，相關規則可參考 [R&A 高爾夫規則](https://www.randa.org/zh-TW/rog/the-rules-of-golf)、[WHO 抗微生物藥物抗藥性說明](https://www.who.int/news-room/fact-sheets/detail/antimicrobial-resistance)。醫療與財經線索只供概念辨識，不包含個人化處置或投資建議。

Noto Sans TC 使用 SIL OFL 授權，dist/FONT-LICENSE.txt 保留全文；PDF 完整嵌入 Regular/Bold。專案尚未指定整體原始碼授權。使用者提供的圖片僅作出題問題與風格參考，沒有複製或上傳至公開程式庫。
