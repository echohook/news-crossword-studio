# 時事填字樂 — 自動題庫網路版 v1.9.0

[開啟網站](https://echohook.github.io/news-crossword-studio/) · [另一入口](https://news-crossword-studio.echoman.chatgpt.site)

開啟網站即載入雲端共用的最新題庫。選擇 1～7 份，按「產生題目」，完成後下載 A4 作答與答案 PDF。不必手動新增、保存或匯入新聞。

## 自動搜尋與加入

雲端約每六小時讀取中央通訊社官方 RSS 的政治、國際、兩岸、財經、科技、生活、社會、地方、體育分類；不讀取娛樂分類，並再次排除娛樂標題及娛樂網址。只使用最近七天的報導標題、日期、來源連結，不擷取全文或圖片。

程式從報導標題中擷取熟悉的 2～4 字國家、地名、人物、機關及用語，產生「新聞標題缺字」提示。答案必須出現在原始來源，提示不洩漏本題或其他候選答案；重疊短詞、已知缺字歧義及不合格資料會排除。這是可重複的用字擷取，沒有宣稱使用 AI 完成完整語意或事實查核。每題保留原始來源，可在「自動題庫」查看。

更新會合併仍在七天期限內的前次新聞，按來源網址去重，最多保留 180 則事件及 500 個不同候選答案。新題庫通過條件後才取代舊題庫，保存於 data/auto-news.json。部分 RSS 失效時使用其他來源；全部失敗或没有合格新題時不覆寫前次資料，下次排程自動重試。網站連線失敗時使用內附最近一次題庫，顯示更新時間與狀態，仍會排除已過期的新聞。

排程約每六小時，設定時間為臺灣 02:17、08:17、14:17、20:17；GitHub 排程可能延後。兩個網站開啟時均載入同一份雲端題庫。「取得最新題庫」取得最近已完成的更新，不會讓每位訪客另行執行蒐集。初次已實際讀取來源並完成題库更新，無須 API 金鑰、付費模型或額外設定。

## 產題規則

每份預設 12 題，優先時事 8 題與成語 4 題；成語不足或無法排入時以時事補足，允許零成語。8×8 優先，9×9 次之，10×10 上限。2、3、4 字平均為最佳化目標；新聞用字不足時不為湊比例加入無來源答案。

同批題目與答案不能重複。候選數量足夠仍不保證能排出全部合法盤面；若指定份數未全數完成，顯示實際份數並禁止下載不完整 PDF，可減少份數或等待更新。首輪自動題庫實测能完成多份，並已下載兩份四頁 PDF。

Solver 與 Validator 保持分離；每份 V01～V08 反向掃描通過，無多餘橫直字串、字衝突或中斷，每題至少一個有效交叉。PDF 橫向用阿拉伯數字、直向用國字；作答頁在前，答案頁在後，只有作答頁顯示填答日期。

產出的題目成果仍在自己的瀏覽器處理，離開前請下載 PDF 或題目檔。自訂題庫的進階工具可用，但其修改只屬本次開啟期間；需要留存時自行匯出，不會覆寫共用自動題庫。四字成語沿用有辭典來源的候選，成語不會阻礙自動時事更新。

## 開發與部署

需要 Node.js 24：

    npm ci
    npm run update-news
    npm --prefix core test
    npm test
    npm run build

news/ 為新聞來源、用字詞表、蒐集與提示產生介面；scripts/update-news.mjs 負責資料更新；src/auto-bank.mjs 負責自動載入、過期排除及離線保留。core/ 仍保留獨立 Solver、Validator、選题及 A4 介面。舊 core/examples/ 為歷史測試資料，不再作為網站的預設新聞題庫。

.github/workflows/pages.yml 在 main 更新、手動啟動及六小時排程時跑完整測試，自動搜尋並保存題庫，再建置、發布 GitHub Pages。只使用平台內建權限；程式無登入憑證或個人 API 金鑰。由平台憑證寫入的題庫提交不另觸發新的更新迴圈。來源完全失效時當次流程失敗，原網站與前次資料持續可用，下次排程重試。

原 Sites 靜態網站維護時沿用 .openai/hosting.json 的 project_id；網站程式更新須走原發布流程，日常題庫更新由共同題庫自動載入，不必重新部署 Sites。

## 驗證与來源

168 項核心測試與 27 項網站／自動題庫測試全數通過，包括「智撤」額外字串、零成語、日期、娛樂排除、來源故障、不覆寫舊資料及提示來源支持。實際瀏覽器驗證自動載入、取得更新、兩份不重複題目、中文 PDF、手機畫面與連線失敗保留原題庫。

新聞來源與使用範圍見 [中央通訊社官方 RSS 說明](https://www.cna.com.tw/about/rss.aspx)，逐題標示發布者與原始網址。Noto Sans TC 使用 SIL OFL 授權，dist/FONT-LICENSE.txt 保留授權全文，PDF 完整嵌入 Regular/Bold 字型。專案尚未指定整體原始碼授權。瀏覽器 WebMCP 使用功能偵測，未宣稱原生支援已驗證。
